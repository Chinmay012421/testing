# SchoolFix

Flask + SQLite school feedback and complaint portal.

## Run

1. Install Python 3.
2. Open Command Prompt in this folder.
3. Run:

   `py -m pip install -r requirements.txt`

4. Start:

   `py app.py`

5. Open `http://127.0.0.1:5000`

Public registration creates Student accounts only. Admin accounts can only be created by a Main Admin through the approval workflow.

Built-in demo Main Admin accounts:
- mainadmin1 / ChangeMe123
- mainadmin2 / ChangeMe456

Change these credentials before any real deployment.
